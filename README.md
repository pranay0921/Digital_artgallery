# 🎨 Digital Art Gallery

A full-stack web application for artists to showcase and manage
their digital artworks.

## 📌 About the Project

Digital Art Gallery is a full-stack web application that allows
users and artists to create accounts, manage profiles, upload
digital artworks, browse artworks by category, and interact with
the gallery.

The project also includes an admin panel for managing users and
artworks.

## ✨ Features

- User registration and login
- JWT-based authentication
- User profile management
- Artist artwork upload
- Browse digital artworks
- Artwork categories
- Artwork details
- Like and comment functionality
- Admin dashboard
- User management
- Artwork management
- Image upload using Multer

## 🛠️ Tech Stack

**Frontend**

**Backend**
- Node.js
